# Synta v67

Current-activity questions such as "to co dokładnie robisz, szczegóły, teraz"
read recorded jobs, their complete assignments, record age, plans and recent
action receipts directly. They do not enter a model work loop or change plans.
Loss complaints return financial evidence without inventing a market cause.
Replay reproducibility is distinct from independent price validation.

A standalone work request no longer inherits three previous conversations.
Only an explicit "do it" follow-up can carry the previous exchange. The current
request takes priority. Long prose ending mid-sentence is rejected even when a
JSON grammar reports stop. One bounded, concise recovery may summarize genuine
receipts, without rerunning tools or applying proposed control actions. Unknown
finish reasons cannot authorize tool execution. This is a targeted validation
rule, not a guarantee that every plausible complete answer is factually correct.

Upgrade archives old informational questions that created short/mid plans,
restores a plan only if that exact version is still current, and requeues the
question through the repaired route. Later operator plans and goals are retained.
Previously executed tools cannot be undone by changing a response record.

Remote setup now distinguishes configured URLs from ready routing. A phone
sign-in is insufficient: Tailscale HTTPS/Serve must be approved by the owner.
The installer checks the gateway, exact private proxy, DNS origin and existing
LAN dashboard before reporting readiness. It retains owner-only authentication
and refuses public Funnel. Local checks do not prove the iPhone can reach it.

Adaptive GPU status includes the request source, actor, request ID, model and
start/end timestamps. It separates Debian requests from Windows local/startup
checks. These are transport receipts, not evidence of training or useful output.
Existing CPU/RTX admission controls remain: browsers allowed, one inference,
65/35/20 percent active-time targets, host load/temperature/RAM/VRAM/observed
power checks. No global hardware limits or clocks are changed.

Validation includes question routing, recovery without tool duplication, exact
plan restoration, standalone context isolation, missing Serve readiness and
GPU proxy receipts. Full regression and lint results accompany publication.
Actual Windows tasks, phone access and thermals cannot be tested on this host.
